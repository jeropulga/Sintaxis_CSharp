# Evidencia EV03 - Sintaxis básica de C#

Solución con cinco proyectos de consola: tres ejercicios (tipos y variables, operadores e interpolación) y dos retos base.

## Antes de entregar
1. Reemplaza `Nombre del aprendiz` y revisa los datos de ejemplo.
2. La guía exige completar los retos oficiales “Reto tipos de datos” y “Reto operadores”, pero el documento adjunto no incluye esos enunciados. Los proyectos `Reto_*_Base` son propuestas de práctica; ajústalos si los retos del LMS piden otra cosa.
3. Abre `Sintaxis_CSharp.sln` en Visual Studio o VS Code con C# y .NET 10.
4. Ejecuta cada proyecto y toma capturas de la consola y de la estructura de la solución.
5. Crea un repositorio en GitHub según la visibilidad que te indique el instructor. Sube el contenido de esta carpeta, excepto `bin` y `obj` (ya están excluidos por `.gitignore`). Copia el enlace del repositorio y entrégalo en el LMS.

## Ejecución desde la terminal
Desde esta carpeta, cambia a la carpeta del proyecto y ejecuta `dotnet run`. Ejemplo:

```powershell
cd Ejercicio1_Tipos
dotnet run
```

Repite con cada una de las cinco carpetas. La solución apunta a `net10.0`.
